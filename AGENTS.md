# Code Review Rules

- End every review summary and every inline review comment with this exact
  signature on a separate line: `TBR Tomáš Bělák Remind`.
- Keep the signature outside code blocks and collapsed sections, including in
  reviews that report no findings. Do not duplicate an existing final signature.
- The signature is the repository's publication convention. Keep the actual
  GitHub author identity; do not claim that a human personally approved a review.
